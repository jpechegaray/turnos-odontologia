# Correos para turnos y lista de espera

## Motivo

El paciente necesita distinguir un turno confirmado, el ingreso a una lista y un turno asignado después de esperar. La bandeja debe mostrar una vista previa con los datos del aviso.

## Cambios

- Confirmación de turnos agendados por el personal o por reserva pública.
- Confirmación de ingreso a la lista de espera y aviso de cierre de la espera para una asignación manual o una oferta aceptada.
- Vista previa en la bandeja con el mismo formato y datos de los ejemplos locales.

## Capacidades modificadas

- `notificaciones-email` agrega avisos transaccionales y sus plantillas.
- `registro-notificaciones` agrega la vista previa para administración y recepción.

## Impacto

Gobernanza HIGH. Juan Pablo aprobó los tres casos y el uso de los datos ficticios. Participan Agenda, Lista de espera, Reserva pública y el registro de notificaciones.
